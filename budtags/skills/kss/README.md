# KSS API (Kiva / Encompass) - Skill Package

A comprehensive Claude skill for the KSS API v1 (kssdata.com) — the data API in front of Encompass, the ERP that Kiva-network distributors run. Built for Budtags imports (products, inventory, customers, invoices, payments, pricing, purchases).

## Provenance — read this before editing

Every file under `categories/` and `patterns/` is a **mechanical 1:1 transcription** of https://kssdata.com/docs/v1 (retrieved 2026-08-19), generated by a deterministic HTML→markdown converter and verified token-for-token against the source: all 40 endpoints, 116 parameters, 47 code blocks, all enum values, and all example-response JSON are byte-exact.

**Do not hand-edit `categories/` or `patterns/` files.** To refresh them when KSS updates their docs:

```bash
curl -sL "https://kssdata.com/docs/v1" -o tools/kss-docs-index.html   # converter reads its own dir
python3 tools/generate_kss_skill.py    # dispatches by CSS class; exits nonzero on any unrecognized element
python3 tools/verify_kss_skill.py     # proves every param/enum/code-block/JSON-field/token survived
```

Then update the retrieval date in both scripts and this README, and archive the new HTML under `source/`. The previous snapshot is `source/kss-docs-v1-2026-08-19.html` (diff against it to see what KSS changed).

Known upstream doc bugs preserved verbatim:
- `GET /users` lists the `States` parameter twice.
- Errors section prose says `error` but the example body uses `"Error"`.
- Invoice status enum is 1,2,3,4,5,7 (no 6).

## What's Included

- **SKILL.md** — entry point: critical conventions, silent-default-filter table, enum reference, domain routing, full endpoint index
- **categories/** — 17 verbatim endpoint-group files (40 endpoints)
- **patterns/** — 6 verbatim intro-section files (getting started, auth, rate limiting, pagination, errors, response headers)

## Key facts

- Auth: `x-api-key` header. Keys are environment-scoped.
- Environments: `api.kssdata.com` (prod) / `api.test.kssdata.com` (test, refreshed every Sunday morning). All endpoints under `/api/v1`.
- Read-only except `POST /payments/applications`.
- Everything is PascalCase; array filters are comma-separated; responses use a `Data` envelope with `Page`/`PageSize`/`HasNextPage`.

## Usage

Invoke: "Use the kss skill" or `/kss-help`, or just ask about Kiva/Encompass/KSS integration.
